## [23] PM 자동화 진행 가능 여부
> 아래 **전부 통과**해야 "진행 가능". 하나라도 미충족이면 **보류**.

- ☐ migration 적용 확인
- ☐ Preview ↔ SQL 값 일치
- ☐ A~E 시나리오 통과
- ☐ AND/OR / 필수설비 / 주력설비 / 취득률 / 선행단계 통과
- ☐ 경과개월 기준 확정
- ☐ 현재 확정 단계 정확(approval_status='승인'만)
- ☐ 중복 criteria 처리 확인
- ☐ 권한/RLS 확인(특히 history append 권한 — [rls-history-analysis.md](./rls-history-analysis.md))
- ☐ 브라우저 오류 없음

**판정**: ☐ 진행 가능 · ☐ 보류(사유: __________)
